这个数据集是怎么组织的

          

            

              
1. 一个任务对应一个目录

              
例如 `opp115_data_security`、`hearsay`、`maud_definition_includes_asset_deals`，每个目录都代表一个具体法律评测任务。

            

            

              
2. 目录内包含说明、Prompt 与数据表

              
常见文件包括 `README.md`、`base_prompt.txt`、`train.tsv`、`test.tsv`。前端读取这些信息，后端据此构造评测请求。

            

            

              
3. 每一行样本都是一次待评测输入

              
表格中的 `text`、`answer` 等字段会被代入 Prompt 模板，组成模型真正看到的输入。

            

          

        


        

          
评测流程说明

          

            
01
选择任务与数据划分，例如 `train` 或 `test`。

            
02
后端读取对应任务目录下的 Prompt 模板与 TSV 数据。

            
03
将样本字段填入模板，生成最终 Prompt，并调用 DeepSeek API。

            
04
对模型输出做归一化处理，例如提取 `Yes/No` 或 `A/B/C/D`。

            
05
将预测结果与标准答案比对，得到单条结果或整体准确率。
